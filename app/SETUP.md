# הקמת האפליקציה: מהדגמה מקומית לעבודה אמיתית

האפליקציה עובדת מיד במצב **הדגמה מקומית** (כל הנתונים בדפדפן, בלי אבטחה). כדי שמנהלי קבוצות ומשתתפים יעבדו יחד, מחברים אותה ל-Firebase. זה חינם בהיקף כזה, והאתר נשאר סטטי (GitHub Pages).

## הרצה מקומית

```bash
python -m http.server 5174
```

ואז לפתוח `http://localhost:5174/app/` (השרת רץ משורש הריפו, כדי שהלוגו מתיקיית `assets` ייטען).

## חיבור ל-Firebase (פעם אחת, כ-10 דקות)

1. ב-[Firebase Console](https://console.firebase.google.com) יוצרים פרויקט חדש (בלי Google Analytics).
2. **Build ← Authentication ← Sign-in method**: מפעילים **Google** ו-**Anonymous** (המשתתפים נכנסים בקוד, בלי הרשמה).
3. **Authentication ← Settings ← Authorized domains**: מוסיפים את `sashka2022.github.io` (ואת הדומיין שבו האתר יעלה).
4. **Build ← Firestore Database**: יוצרים מסד נתונים (מיקום `europe-west1` או קרוב אחר, מצב Production).
5. **Firestore ← Rules**: מדביקים את התוכן של `app/firestore.rules` ולוחצים Publish. לפני כן מוודאים שרשימת המיילים של מנהלי העל בכללים זהה ל-`SUPER_ADMINS` ב-`app/js/config.js`.
6. **Project settings ← Your apps ← Web (</>)**: רושמים אפליקציה, ומעתיקים את אובייקט ה-config אל `FIREBASE_CONFIG` ב-`app/js/config.js`. (המפתח הזה ציבורי מטבעו. האבטחה נשענת על הכללים בשלב 5.)
7. נכנסים לאפליקציה עם חשבון מנהל.ת העל, ובדף "הקבוצות שלי" מוסיפים בתחתית את המיילים של מנהלי הקבוצות.

## בדיקה אחרי החיבור

* מנהל.ת עם חשבון שאינו ברשימה מקבל.ת הודעה "החשבון הזה לא מורשה לנהל קבוצות".
* משתתף.ת מזין.ה קוד שגוי: "הקוד לא נמצא".
* משתתף.ת שלא פורסם לו הסילבוס רואה "הסילבוס עוד לא פורסם".
* שני משתתפים בצוות אחד: מי שפתח ראשון הוא הממלא, והשני רואה את הכתיבה בזמן אמת.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html`, `styles.css`, `js/main.js` | מעטפת האפליקציה, ניתוב לפי hash |
| `js/views/*` | מסכים: כניסה, ניהול קבוצות, סילבוס, מסע, הובלת יוזמה, משתתפים, הגדרות |
| `js/store.js`, `js/localdb.js` | שכבת נתונים: Firestore, או הדגמה מקומית באותו ממשק |
| `js/model.js` | שלבי התהליך, תבנית תחנות, קודי קבוצה |
| `initiative.html`, `js/workspace-host.js` | מרחב העבודה של הצוות (אפליקציית עץ הבעיה) והחיבור שלו לנתונים |
| `firestore.rules` | כללי אבטחה |
